# 0007: Licence for code and documents

- Status: accepted
- Date: 2026-11-23

## Decision

- Code in `tools/`: Apache License 2.0. It is fully open and includes an explicit patent grant from every contributor, so no one who contributes can later claim a patent against anyone using the code. That protects the no-patents commitment.
- Charter, decisions and documentation: Creative Commons Attribution 4.0 (CC BY 4.0).
- Data: ODbL 1.0 (decision 0006).

## Resolution

Accepted on 2026-11-23. The full licence texts are in the repository root:

- `LICENSE`: Apache License 2.0, for code.
- `LICENSE-DOCS`: CC BY 4.0, for the charter, decisions and documentation.
- `LICENSE-DATA`: ODbL 1.0, for data (decision 0006).

`NOTICE` says which licence covers which part, as Apache 2.0 expects.
