# VITA-SHIELD Charter

## Purpose

To prevent snakebites before they happen, and to end deaths and disabilities from snakebite everywhere, while keeping both people and snakes safe.

## Philosophy

- **Vasudhaiva Kutumbakam.** The world is one family, and that family includes the snake. The commons serves every person and every creature equally, without borders.
- **Enhancing efficiency everywhere.** One problem, one goal, one shared source of truth. Collect once, use everywhere, never duplicate.

## Ownership: a sovereign digital commons

- VITA-SHIELD is held in stewardship, not ownership. No person, company or state owns it.
- No patents will be sought on any part of it, and its work is published openly so it remains prior art for all.
- Each contributing nation, institution and community keeps sovereignty over the data it contributes, and decides what is shared and with whom.
- Personal and patient data is protected by design and shared only within clear, consented boundaries.

## Built once, to last

The data layer is designed to outlive any technology, company or programming language that touches it:

1. **Open, plain formats.** UTF-8 text, CSV and JSON as the canonical forms. Nothing depends on proprietary software to be read.
2. **Permanent identifiers.** Every record gets an identifier that is never reused, never changed and never tied to a name, because names change and identifiers must not.
3. **Nothing is overwritten.** Every change is a new version with its date and reason. History is kept, never erased.
4. **Provenance for every record.** Where it came from, when it was retrieved, under what licence, and who verified it.
5. **Universal reference frames.** Time in UTC (ISO 8601), measurements in SI units, location in a stated coordinate reference system with the celestial body named, Earth by default.
6. **Rebuildable by anyone.** Canonical data is generated from raw sources by open scripts, so every record can be verified and reproduced.
7. **Self-describing.** Every dataset carries its own documentation, so a reader generations from now needs nothing else to understand it.
